# Portafolio Personal

## Descripción

Este proyecto corresponde a mi primer portafolio web personal.

El objetivo es presentar mis habilidades, proyectos y formas de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Características

- Diseño responsive
- HTML semántico
- Navegación mediante menú
- Sección de presentación
- Sección de habilidades
- Sección de proyectos
- Sección de contacto
